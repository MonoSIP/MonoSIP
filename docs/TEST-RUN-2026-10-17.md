## Fixes applied during this run

1. **`config-writer.ts` PJSIP** — removed invalid multi-value `transport=` on endpoints (SIP INVITE 500).
2. **Main IVR** — `xfer-sales` failure exits → validate/publish v4.
3. **`config-writer.ts` System(curl)** — all internal API posts use `Set()` flat vars + single-quoted JSON (`internalPost` / `qosPrepLines`). Fixes Fastify `Body is not valid JSON` for DND, CDR, recording, missed, voicemail, queue-callback.
4. **Harness** — `DTMF_DELAY_MS`, `DTMF_PHASES`, `CALL_HOLD_MS`, `NO_ANSWER`, `BUSY=1` (486), feature codes `*78`, BYE on success exit.
5. **`Alert-Info`** — escape `;` as `\;` so distinctive-ring header is not truncated by dialplan comments.
6. **Answer path + hangup CDR** — after Dial, `ANSWER` → Hangup; failures → `s-${DIALSTATUS}`; `h` extension posts CDR when caller BYE aborts Dial (sets `DSIP_CALLEE` / `DSIP_CDR_DONE`).
7. **PJSIP AOR** — `qualify_frequency=30`, `remove_unavailable=yes` (frees slots on REGISTER overflow), `maximum_expiration=300` so dead bindings age out.
8. **`db-setup.ts`** — auto-migrate `dsip_test` so host vitest stays aligned with Drizzle (fixes `from_domain` drift).
