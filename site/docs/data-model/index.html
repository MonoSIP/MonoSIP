MunaSIP data model

All settings live in PostgreSQL; Asterisk config is generated from here. Destination fields use the same pair everywhere: dest_type + dest_id.

TableMain fields
extensionsnumber, name, email, sip_secret (encrypted), portal_password_hash, portal_enabled, recording_mode, recording_listen_allowed, outbound_cli, call_permissions, mobile_forward_allowed, dnd, voicemail_pin
extension_forwardingextension_id, status (no_answer / busy / unavailable), ring_seconds, dest_type, dest_id
devicesextension_id, model, mac, provisioning_profile, last register time
ring_groupsname, number, strategy, ring time, unanswered destination
ring_group_membersring_group_id, extension_id, order
queuesname, number, strategy, member_timeout, wrapup, max_wait, max_callers, announce settings, moh_id, schedule_id, overflow destinations, callback_enabled
queue_membersqueue_id, extension_id, penalty, paused, pause_reason
schedulesname, timezone, override_mode, override_until
schedule_rangesschedule_id, day, start, end, status (open / lunch)
holidaysschedule_id (null = global), date, half-day flag, name
trunksname, host, port, transport, auth_type, username, secret (encrypted), codecs, max_channels, number format rules, status
inbound_routesdid, caller_pattern, priority, dest_type, dest_id
outbound_routesname, pattern, prefix rewrite, ordered trunk list, required permission
blacklistnumber or pattern, direction, note
flowsname, draft_json, published_version_id
flow_versionsflow_id, version number, json, published_at
secretsencrypted tokens/passwords for API nodes
promptsname, language, file path, TTS source
moh_classesname, files
cdrcall_id (linkedid), start, answer, end, direction, caller, callee, did, extension, queue, disposition, duration, trunk_id, recording_id, dnd_flag, quality (jitter, loss, MOS)
call_eventscall_id, time, type, data (CEL and flow steps; IVR DTMF reports come from here)
queue_eventsAsterisk queue_log rows
recordingscall_id, file path, duration, size, deleted_at, archived flag
recording_access_logrecording_id, who (admin / extension), time
missed_callsnumber, destination, time, status (waiting / called_back), return call_id
voicemailsextension_id, caller, time, file, read flag
spend_limitsscope (global / extension), daily and monthly limits, current usage
webhooksURL, event types, signing key, active flag
api_keysname, hash, permissions, last used
audit_logactor, action, object, before/after, IP, time
settingsglobal settings (KVKK retention, SMTP, backup, IP restrictions, hostname/SSL)
