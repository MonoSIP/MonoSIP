MunaSIP admin and portal screens

The admin panel has 15 screens; the user portal has 5. Both live in the same Vite app with different layouts by role.

Admin panel

ScreenContent
DashboardActive calls, queue waiters, extension state, trunk status, today’s summary; full-screen (TV) mode
ExtensionsList (state, DND, device); detail tabs: general, forwarding, permissions, recording, portal, devices; CSV import/export
Ring groupsList and edit
QueuesList; detail: settings, members (drag-and-drop order, pause), announces, overflow destinations
SchedulesWeekly editor, holiday calendar, manual override, “now” status
IVR (flows)List; designer: canvas, node palette, node settings, simulation panel, version history
TrunksSIP provider list, create form, live status
RoutesInbound and outbound routes, blacklist
PromptsUpload announcements, generate via TTS, live TTS cache
Music on holdClasses (unique names), upload, preview, delete
RecordingsFiltered list, waveform player, download, access log
Call logsFiltered CDR table; a clicked row expands in place with call facts and the IVR step timeline; CSV export
Missed callsWaiting / called-back list
ReportsSummary, queue, extension, IVR DTMF, quality; date range
IntegrationWebhooks, API keys
SettingsGeneral; security (admin/portal/SIP IP allowlists, denylist, bans, firewall export, login flood); country/spend limits; KVKK; email; backup; audit log; 2FA

User portal

ScreenContent
PhoneSoftphone: keypad, call on the phone screen, recent calls behind a button; a mini phone appears on every other portal page
DirectoryCoworkers and presence, dial
My callsInbound, outbound, missed; callback
My recordingsList and player (listen only)
My settingsDND, forwarding, voicemail, password, audio devices

Shared UI rules

  • Desktop left nav; mobile bottom tabs (portal) or hamburger (admin)
  • Light/dark theme; follows system preference, overridable
  • Tables become cards on mobile; flow designer is view-only on mobile
  • Default UI language is English (Turkish available in-app). Dates/numbers use locale formatting
