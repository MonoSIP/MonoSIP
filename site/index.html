Install

Clone, copy env, generate lab certs, bring the stack up. Data lives in Docker volumes — rebuilds keep your database and recordings. 

git clone https://github.com/diggyen/DSip.git
cd DSip
cp .env.example .env
./scripts/gen-certs.sh
docker compose up --build -d
# → https://localhost

Full guide: docs/INSTALL.md · VPS / phones: docs/DEPLOY-VPS.md

Built for the desk and the browser

One stack for trunks, queues, IVR, softphone, and ops — not a call-center suite bolted onto a host you can’t touch.

  • Extensions & routes Permissions, DND, forwarding, blacklist, emergency 112 always open.
  • Queues & schedules Announce position, callback, holidays, per-status destinations.
  • IVR designer Visual flows on ARI — menus, API nodes, TTS, publish & rollback.
  • Softphone + desks SIP.js over WSS, coturn, provisioning QR for desk phones.
  • Live ops Dashboard, spy/whisper, CDR, recordings, reports, webhooks.
  • Hostname SSL Let’s Encrypt from Settings — issue, install, renew on its own.
