03 · Call flow

A menu, a lookup, then a sentence

The demo line on 902 welcomes the caller, offers sales and the support queue, then reads a live exchange rate. Drafts stay off the phones until you publish.

  • A shape for each step. Start, announce, menu, transfer, queue, API, condition and hangup each have their own shape and color. Drag one onto the map, open it with the pencil, and draw the exit to the next step.
  • The demo call on 902. It welcomes the caller, offers sales and the support queue, plays “one moment”, then fetches the exchange rate and reads it out. Pressing a key during a prompt stops the prompt and keeps the digit.
  • Live data. An API node sends GET, POST, PUT, PATCH or DELETE. You set the URL, a timeout, a retry and auth — none, Basic, Bearer or a custom header. The secret stays encrypted in Settings and never lands in the flow file. A JSON path such as $.rates.usd becomes rate, and the next node speaks it.
  • The caller stays in the sentence. $caller, $did and any digit you collect can be spoken, or sent onward in the request URL and body. Filters turn a plate code into a province, a price into words, or a number into digits read one by one.
  • Every exit is a branch. A menu has a path per digit, plus timeout and invalid. A transfer has busy, no answer and unavailable. A busy extension is caught before the phone rings, so the caller hears the busy path and the desk does not ring.
  • Try it, then publish. The test call walks the draft with a caller number, a time and keypresses, and highlights the nodes it visited. Live calls keep using the published version. An older one is a click away, and a call already in progress finishes on the version it started with.

05 · On your server

Pull the image. The PBX is up.

Asterisk, the API, the panel, PostgreSQL and the speech engines live in one image on GitHub Container Registry. A deploy pulls it. It does not build it.

  1. Point a hostname at the server and open TCP 80/443 and UDP 10000–10100 (RTP).
  2. Run the image with a volume on /data.
  3. Sign in, set the hostname in Settings and issue the certificate.

Recommended: 2 vCPU and 4 GB RAM or more (neural speech runs on the PBX’s CPU). Expose SIP 5060 only if desk phones or trunks need it.

bash
# prebuilt image (linux/amd64)
docker run -d --name munasip --restart unless-stopped \
  -p 3000:3000 -p 10000-10100:10000-10100/udp \
  -v munasip-data:/data \
  -e EXTERNAL_IP=203.0.113.10 \
  -e PUBLIC_HOST=pbx.example.com \
  ghcr.io/munasip/munasip:latest

# update: data stays in the munasip-data volume
docker pull ghcr.io/munasip/munasip:latest
