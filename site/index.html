DSip

Company PBX you run yourself — Asterisk, panel, and softphone in one Compose stack.

Built for offices around ~20 extensions: trunks and queues, visual IVR, browser softphone over WSS, CDR and recordings, hostname SSL from Settings. Default UI English; Turkish available.

Telephony that covers the desk

Not a hosted black box — you keep the media plane (Asterisk) and the control plane (Fastify + React) on your VM. Everything below ships in the open-source stack.

Extensions

CRUD plus CSV import/export for bulk desks. Per-extension outbound CLI, call permissions (local / mobile / 444 / international), server-side DND (*78/*79), forwarding chains (max depth 5), voicemail, directed pickup, BLF hints, and distinctive ring tones. Emergency 112 is always allowed regardless of permission class.

Queues & ring groups

Asterisk queue strategies: ringall, leastrecent, fewestcalls, rrmemory, linear, random. Member penalty and wrap-up, max wait / callers, MOH class, TTS for position & estimated hold-time, overflow destinations, and queue callback (“press 1 to keep your place”). Simpler ring groups when you only need ringall or linear hunt.

Schedules & holidays

Weekly ranges with lunch status, TR holiday pack, company-specific days, manual override (open / closed / auto), and a separate destination per status. Timezone default: Europe/Istanbul.

Trunks & routes

Multi-trunk SIP providers, inbound DID / caller patterns, outbound patterns & permissions, blacklist, anonymous inbound block, country allowlist, daily/monthly spend limits, and last-dial callback (12h) when a missed number calls back.

IVR / flow designer

Visual ARI canvas: menu, Get key ($pin), API (GET/POST…), TTS, queue, transfer. Pencil opens settings; drag only moves. Validate, publish, rollback, simulate. See the panel →

Recording & CDR

MixMonitor with optional KVKK announcement, retention job, Opus convert when ffmpeg is present, local/NAS/SFTP archive. CDR filters, CSV export, call timeline, missed-call list with “called back” tracking.

IVR designer in the admin panel

Build the call path on a map. Drag nodes to arrange; use the pencil to edit. Variables from Get key, Set variable, or API mappings expand as $name or {{name}} in prompts and HTTP fields.

Softphone & desk phones

Same PBX for browser users and SIP handsets — credentials and presence from the portal, provisioning for common desk brands.

Browser softphone

  • SIP.js over wss://…/asterisk-ws (TLS at nginx → Asterisk HTTP)
  • coturn TURN for off-site WebRTC when UDP is blocked
  • Directory & presence, own calls, listen-only recordings, voicemail
  • Forwarding and DND from the portal without touching the desk set

Desk & provisioning

  • Yealink / Fanvil / Grandstream-style MAC provisioning
  • QR softphone setup for quick onboarding
  • Point phones at EXTERNAL_IP:5060 with portal SIP password
  • Prefer locking SIP/RTP to office, VPN, or trunk IPs

Ops, security, SSL

Day-two tools live in the admin panel — not a second product.

Live dashboard

WebSocket fan-out for active calls, queues, extensions, trunks. TV / full-screen mode. Spy, whisper, and barge via ARI snoop (audited).

Reports & integrations

Summary, queue, extension, IVR DTMF, quality. Daily/monthly email when SMTP is set (otherwise log-only). Webhooks + API keys for originate, CDR, recordings.

Hostname & auto SSL

Settings → public hostname + Automatic SSL (Let’s Encrypt HTTP-01). Certs write to docker/nginx/certs; nginx reloads; renew checked on a schedule.

Security

Admin 2FA (TOTP, Add to Apple Passwords). IP allowlists, login flood bans, optional fail2ban profile, nftables/ufw export from Settings.

Stack & persistence

Rebuild images anytime — named volumes keep PostgreSQL, recordings, uploads, and generated Asterisk config.

Install

Lab on localhost in minutes. Production: set public host / IP, strong secrets, then enable Automatic SSL in Settings. 

git clone https://github.com/diggyen/DSip.git
cd DSip
cp .env.example .env
chmod +x scripts/gen-certs.sh && ./scripts/gen-certs.sh
docker compose up --build -d
# → https://localhost   (accept self-signed warning)

Lab logins

  • Admin: admin@example.com / Admin123!
  • Portal: 101 / portal101
  • Change passwords before any real traffic

Don’t lose data

  • docker compose up --build keeps volumes
  • docker compose down -v deletes DB & recordings
  • Guide: INSTALL.md
